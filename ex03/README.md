# Project00

A beginner project for practicing shell commands and Git.

## Exercises

- `ex00/tree_structure.txt` contains a sample directory structure.
- `ex01/manage_files.sh` creates, edits, copies, moves, and removes files.
- `ex01/run_log.txt` contains the script output.
- `ex02/git_log.txt` contains Git history.
- `ex02/repo_url.txt` contains the repository URL.
- `ex03/` is reserved for a future exercise.

Run the shell exercise with:

```bash
bash ex01/manage_files.sh
```

## Why Git Makes Development Easier

Git makes development easier in three main ways:

- **Safeguards code:** commits save checkpoints, so broken changes can be reviewed or undone.
- **Tracks history:** commits show what changed, when it changed, and who changed it.
- **Enables collaboration:** developers can work on branches, share changes, and merge their work.

## Basic Git Workflow

1. Edit files.
2. Run `git add` to stage them.
3. Run `git commit` to save the changes.
4. Run `git push` to send them to the remote repository.

See [`git_workflow.txt`](git_workflow.txt) for the commands.
